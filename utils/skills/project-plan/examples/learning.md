# Learning

Planning on learning should have:

input -- a goal
output -- a directed-acyclic graph of dependencies

Each node of the output should have as much content as
a textbook section or a single lecture.

Notice that different topics, depending on depth, could
have a completely different number of nodes. Do not hesitate
to produce an incredibly big DAG if the topic requested is
complex enough.

## Algorithm

You can work the directed acyclic graph it out in a top-down manner.
For example, if the goal would be worthy of a whole textbook,
you might first decide which could be the chapters of that textbook.
Then, you can split each chapter in sections.
