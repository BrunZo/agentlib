# Definitions

| term | meaning |
| ---- | ------- |
| Epic | A large body of work too big to implement directly. Example: “Add collaborative editing.” |
| Story | A small piece of user-visible value. Often phrased. |
| Task | Concrete implementation work needed to complete a story. Example: “Add WebSocket endpoint.” |
| Story points | Relative estimate of effort/complexity/uncertainty. They are NOT hours. A 5-point story should feel substantially bigger than a 2-point one |
